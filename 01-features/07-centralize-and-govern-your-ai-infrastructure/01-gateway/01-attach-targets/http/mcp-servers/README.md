# MCP Server HTTP Targets

> [!NOTE]
> This section is under construction.

Attach MCP servers to the gateway as HTTP targets, addressed directly through
path-based routing (no aggregation). Covers MCP servers on AgentCore Runtime and
public third-party MCP servers fronted via passthrough.

# Agent Core Browser Tool Integrations

This directory contains production-ready browser tool integrations for various agentic frameworks. These integrations provide comprehensive implementations that can be used directly in production environments.

## Available Integrations

### 03-browser-with-Strands
Complete Strands framework integration with browser tool capabilities. This integration provides production-ready code for implementing browser automation with the Strands agentic framework.

**Features:**
- Full browser automation capabilities
- Strands framework integration
- Production-ready configuration
- Example usage and setup scripts

### 04-browser-with-LlamaIndex
Comprehensive LlamaIndex integration with advanced browser tool functionality. This integration offers a complete solution for browser automation within LlamaIndex-based applications.

**Features:**
- Advanced browser automation
- LlamaIndex framework integration
- Comprehensive configuration options
- Extensive documentation and examples
- Production deployment support

## Getting Started

Each integration directory contains:
- Complete implementation code
- Configuration files and templates
- Setup and installation scripts
- Documentation and usage examples
- Test files and validation scripts

Navigate to the specific integration directory for detailed setup instructions and usage examples.
